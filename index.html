NetWatch

Lab-only network security analysis pipeline

NetWatch scans a lab network with Nmap and analyzes Wireshark captures, saved or live, for attack patterns. It scores the risk of each finding and suggests firewall rules without ever applying them.

  • Five-stage pipeline: capture, detect, score, respond, report
  • 12 attack scenarios, including ARP spoofing, DNS tunneling, SYN floods and rogue DHCP
  • Flask web dashboard and JSON API, with reports in Markdown, HTML, JSON and JSONL
  • Safety rules enforced in code: private networks only, explicit consent, secrets masked
Role
Solo — architecture, detectors, scoring, web UI, tests

NISHAAN

AI crime-scene sketching tool

A witness describes a suspect in English, Hindi or Kannada. NISHAAN turns the description into a composite sketch that can be refined and a realistic 3D head. Officers can lock features and track version history, with case evidence and the timeline kept together.

  • Two services: a React + FastAPI app and a Flask service that drives Blender for 3D
  • Staff and witness roles, an audit trail and an offline mock mode

WEFT

Service-dependency blast-radius analyzer

WEFT answers the question "if this service fails, what else breaks?" It imports Jaeger or OTLP traces and rebuilds the microservice call graph. Then it scores health and criticality and simulates failures to show the blast radius, likely root causes and mitigations.

  • Deterministic graph analysis with NetworkX, scoring criticality on five weighted factors
  • Safe by design: never touches production services
