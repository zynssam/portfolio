# Samrudh Shetty — Portfolio

Personal portfolio of **Samrudh Shetty**, AI & Software Development Engineer and CS student at REVA University, Bengaluru.

**Live site:** https://zynssam.github.io/portfolio/

A single-page site in a Swiss / International Typographic style: one HTML file, no frameworks or build step. Images are embedded, so `index.html` works on its own.

- Click-to-jump navigation with a scroll-synced active section, progress bar and side index
- Scroll animations (respects `prefers-reduced-motion`)
- Sections: About · Work · Skills · Achievements · Experience · Projects · Contact

To run locally, open `index.html` in a browser.
